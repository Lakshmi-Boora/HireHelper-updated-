# 🧑‍🤝‍🧑 Hire-A-Helper

> Empowering people to connect, collaborate, and complete tasks efficiently — built with the **MERN Stack + TypeScript**.


---

## 🌟 Introduction

**Hire-A-Helper** is a full-stack web application designed to simplify collaboration.  
It allows users to **post tasks**, **request to help on others’ tasks**, and stay connected through **notifications and real-time updates**.

Whether you need help or want to lend a hand, this app makes the process smooth, secure, and interactive — powered by modern web technologies.

## ✨ Features

### 🔐 Authentication
- Register & Login using email  
- Email-based OTP verification via **Nodemailer (Gmail)**  
- JWT-based authentication and secure routes  

### 🧾 Task Management
- Post new tasks with details, location, and time  
- View personal tasks under “My Tasks”  
- Browse available tasks from others in the Feed  

### 🙋 Request Handling
- Send requests to help on available tasks  
- Task owners receive notifications in real-time  
- Track all sent and received requests with status  

### 🧑‍💼 Profile Management
- Update name, email, phone, and profile picture  
- Manage personal settings directly from the dashboard  

### 🖥️ Dashboard & UI
- Clean, modern UI with sidebar navigation  
- Responsive design built using **React + Tailwind CSS**

## 🧩 System Workflow

### 🔄 Overall Flow

User → Register/Login → OTP Verification  
  ↓  
Dashboard Loaded  
  ↓  
Post New Task   
  ↓       

Task Added to Feed   
   ↓  
Other Users → View Feed → Request Help  
  ↓  
Task Creator Receives Notification  
  ↓  
Accept/Reject Request  
  ↓  
Connection Established  

---

### 🧠 Behind the Scenes
- User details securely stored after registration.  
- OTP sent using Nodemailer to verify identity.  
- Authenticated users receive a JWT token.  
- Task data saved in MongoDB linked to the creator.  
- When a request is made, it’s recorded in the **Requests** collection and triggers a **Notification** for the task creator.

## 🗃️ Database Design

### 🧑‍💻 1. User
| Field | Type | Description |
|-------|------|-------------|
| `_id` | `ObjectId` | Unique user ID (auto-generated by MongoDB) |
| `first_name` | `String` | User's first name (required) |
| `last_name` | `String` | User's last name (optional) |
| `email_id` | `String` | Email address (required, unique) |
| `password` | `String` | Encrypted password (hashed using bcrypt, required) |
| `phone_number` | `String` | Contact number (optional) |
| `profile_picture` | `String` | URL or file path of the profile image (optional) |
| `bio` | `String` | User biography/description (optional) |
| `otp` | `String` | One-time password for verification |
| `otpExpires` | `Date` | OTP expiration timestamp |
| `isVerified` | `Boolean` | Email verification status (default: false) |
| `canResetPassword` | `Boolean` | Password reset permission (default: false) |
| `createdAt` | `Date` | Timestamp when user was created |
| `updatedAt` | `Date` | Timestamp when user was last updated |

---

### 📋 2. Task
| Field | Type | Description |
|-------|------|-------------|
| `_id` | `ObjectId` | Unique task ID (auto-generated by MongoDB) |
| `user_id` | `ObjectId` | Reference to the creator (User, required) |
| `title` | `String` | Task title (required, trimmed) |
| `description` | `String` | Detailed task description (optional, trimmed) |
| `category` | `String` | Task category (required) |
| `location` | `String` | Task location (required) |
| `picture` | `String` | Optional image or media file |
| `startTime` | `Date` | Start time of the task (required) |
| `endTime` | `Date` | Optional end time |
| `status` | `String` | Task status (`pending`, `in-progress`, `completed`, default: `pending`) |
| `createdAt` | `Date` | Timestamp when task was created |
| `updatedAt` | `Date` | Timestamp when task was last updated |

---

### 🤝 3. Request
| Field | Type | Description |
|-------|------|-------------|
| `_id` | `ObjectId` | Request ID (auto-generated by MongoDB) |
| `task_id` | `ObjectId` | Reference to the task being requested (required) |
| `requester_id` | `ObjectId` | Reference to the user sending the request (required) |
| `description` | `String` | Request description/message (required) |
| `status` | `String` | Request status (`pending`, `accepted`, `rejected`, default: `pending`) |
| `createdAt` | `Date` | Timestamp when request was created |
| `updatedAt` | `Date` | Timestamp when request was last updated |

---

### 🔔 4. Notification
| Field | Type | Description |
|-------|------|-------------|
| `_id` | `ObjectId` | Notification ID (auto-generated by MongoDB) |
| `user_id` | `ObjectId` | Reference to the notification receiver (required) |
| `message` | `String` | Notification message text (required) |
| `isRead` | `Boolean` | Read status of notification (default: false) |
| `createdAt` | `Date` | Timestamp when notification was created |
| `updatedAt` | `Date` | Timestamp when notification was last updated |

---

### ✅ 5. AcceptedTask
| Field | Type | Description |
|-------|------|-------------|
| `_id` | `ObjectId` | Accepted task ID (auto-generated by MongoDB) |
| `task_id` | `ObjectId` | Reference to the original task (required) |
| `user_id` | `ObjectId` | Reference to the helper/user who accepted (required) |
| `status` | `String` | Acceptance status (`active`, `completed`, default: `active`) |
| `createdAt` | `Date` | Timestamp when task was accepted |
| `updatedAt` | `Date` | Timestamp when acceptance was last updated |

## 🌐 API Endpoints

### 🔐 Authentication
- **POST** `/api/auth/register` - Register a new user
- **POST** `/api/auth/verify-otp` - Verify email with OTP
- **POST** `/api/auth/resend-otp` - Resend OTP to email
- **POST** `/api/auth/login` - Log in and get JWT token
- **POST** `/api/auth/forgot-password` - Initiate password reset
- **POST** `/api/auth/reset-password` - Reset password with token
- **POST** `/api/auth/logout` - Log out user

### 📋 Tasks
- **POST** `/api/tasks/add` - Create a new task
- **POST** `/api/tasks/` - Create a new task (alternative)
- **GET** `/api/tasks/my-tasks` - Get current user's tasks
- **GET** `/api/tasks/feed` - Get all tasks for feed
- **GET** `/api/tasks/:id` - Get specific task by ID
- **PUT** `/api/tasks/:id` - Update a task
- **DELETE** `/api/tasks/:id` - Delete a task

### 🤝 Requests
- **POST** `/api/requests/:taskId` - Send request for a task
- **GET** `/api/requests/my` - Get current user's sent requests
- **GET** `/api/requests/for-my-tasks` - Get requests for user's tasks
- **GET** `/api/requests/for-task/:taskId` - Get requests for specific task
- **PATCH** `/api/requests/:id/accept` - Accept a request
- **PATCH** `/api/requests/:id/reject` - Reject a request
- **DELETE** `/api/requests/:id` - Cancel/delete a request

### ✅ Accepted Tasks
- **GET** `/api/accepted-tasks/my` - Get user's accepted tasks
- **PATCH** `/api/accepted-tasks/:id/complete` - Mark task as completed

### 🔔 Notifications
- **GET** `/api/notifications/my` - Get user's notifications
- **PATCH** `/api/notifications/:id/read` - Mark notification as read

### ⚙️ Settings
- **GET** `/api/settings/profile` - Get user profile
- **PUT** `/api/settings/profile` - Update user profile
- **PUT** `/api/settings/password` - Update password
- **PUT** `/api/settings/profile-picture` - Update profile picture
  
## 🛠️ Installation & Setup


Follow these steps to run the project locally on your system 👇  

---

### 1️⃣ Clone the Repository

git clone https://github.com/Lakshmi-Boora/Internship_Infosys_2025_Hire_A_Helper_Team_04.git

cd Internship_Infosys_2025_Hire_A_Helper_Team_04

### 2️⃣ Install Dependencies
Install all required packages for both the backend and frontend.
#### 🖥️ Backend

cd backend

npm install

#### 💻 Frontend

cd frontend

npm install

### 3️⃣ Configure Environment Variables
Create .env file for backend folder.

#### ⚙️ Backend .env

PORT=2000

NODE_ENV=development

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

EMAIL_USER=your_gmail_address

EMAIL_PASS=your_gmail_app_password


### 4️⃣ Start the Servers
Once setup is complete, run both servers.

#### 🖥️ Run Backend

cd backend

npm run dev

#### 💻 Run Frontend

cd frontend

npm run dev

#### 🌐 Open the App

After both servers are running successfully, open the app in your browser:

Then open the app at:

👉 http://localhost:5173
